## 📋 Sobre o Projeto

O **Automação ComprasNet** é um repositório focado em otimizar processos, consultas e rotinas dentro do portal oficial de compras do Governo Federal (**Compras.gov.br**). 

> ⚠️ **Nota de Transparência:** Todos os códigos e scripts contidos neste repositório são integralmente escritos por **Inteligência Artificial (IA)**, servindo como um experimento prático de desenvolvimento assistido por IA para automação de tarefas no navegador.

---

## ✨ Funcionalidades Principais

- **Automação via Navegador:** Execução rápida direto no navegador através de UserScripts.
- **Consulta e Monitoramento:** Agiliza a visualização de editais, avisos e processos de interesse.
- **Redução de Trabalho Manual:** Elimina tarefas repetitivas e burocráticas no dia a dia do portal.

---

## 🛠️ Tecnologias Utilizadas

* [Tampermonkey](https://www.tampermonkey.net/) (Gerenciador de UserScripts)
* JavaScript / HTML / CSS
* **Inteligência Artificial** (Responsável pela criação, lógica e estruturação de todos os códigos)

---

## ⚙️ Como Instalar e Usar

Para utilizar os scripts deste repositório, você precisará de uma extensão de gerenciamento de usuários no seu navegador:

1. Instale a extensão **Tampermonkey** no seu navegador (disponível para Chrome, Firefox, Edge, etc.).
2. Navegue até a pasta do script desejado neste repositório.
3. Copie o código fonte ou clique em "Raw" no arquivo `.user.js`.
4. O Tampermonkey abrirá automaticamente uma janela para você confirmar a instalação do novo script.
5. Acesse o portal [Compras.gov.br](https://www.comprasnet.gov.br) e o script será executado conforme configurado.
